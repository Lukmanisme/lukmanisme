Kebijakan Privasi (Privacy Policy)

Kebijakan Privasi ini menerangkan bagaimana Balanjo POS dan Lukmanisme POS Studio mengumpulkan, mempergunakan, menyimpan, dan menjaga keamanan informasi pribadi serta data operasional usaha Anda ketika mengakses portal web resmi maupun menggunakan aplikasi kasir Android Balanjo POS. Kami berkomitmen menjunjung tinggi hak privasi pengguna sesuai perundang-undangan perlindungan data pribadi yang berlaku di Indonesia.

1 Data & Informasi yang Kami Kumpulkan

  • Data Identitas Akun Pemilik Usaha: Nama pemilik, nama toko/warung, nomor telepon/WhatsApp, dan alamat email yang Anda berikan saat melakukan registrasi di aplikasi kasir atau saat checkout perpanjangan di portal web.
  • Data Transaksi Pembayaran Langganan: Nomor pesanan (Order ID), paket langganan yang dipilih, jumlah nominal pembayaran, waktu transaksi, dan status verifikasi pembayaran yang kami terima dari gateway Midtrans.
  • Pengenal Perangkat (Device Fingerprint): Hash kriptografis satu arah dari nomor identitas perangkat Android (Android ID / Installation UUID) yang digunakan semata-mata untuk mencegah penyalahgunaan klaim masa uji coba gratis (Free Trial Abuse) berulang pada perangkat yang sama.
  • Data Transaksi Kasir Lokal: Riwayat penjualan harian, nama produk, kategori menu, dan harga jual tersimpan secara privat di dalam internal ponsel kasir Anda (SQLite). Kami tidak menjual maupun membagikan data riwayat penjualan internal warung Anda ke pihak ketiga manapun.

2 Pemrosesan Pembayaran via Midtrans (Payment Gateway)

Seluruh transaksi pembayaran perpanjangan langganan diproses melalui gerbang pembayaran terpercaya PT Midtrans (Midtrans Payment Gateway).

  • Saat melakukan pembayaran, data pesanan (Order ID, Email, Nama Toko, Jumlah) dikirimkan secara terenkripsi ke server Midtrans untuk pembuatan QRIS Dinamis atau nomor Virtual Account bank.
  • Standar Keamanan Tertinggi: Pemrosesan pembayaran memenuhi standar internasional PCI-DSS (Payment Card Industry Data Security Standard) Level 1 yang dikelola langsung oleh infrastruktur Midtrans.
  • Balanjo POS tidak pernah meminta, mengakses, mencatat, ataupun menyimpan nomor kartu kredit/debit, kode CVV/CVC, maupun kata sandi perbankan Anda.

3 Tujuan Penggunaan Informasi

Informasi yang kami peroleh digunakan secara terbatas untuk tujuan:

  • Mengidentifikasi akun pengguna dan memverifikasi keabsahan lisensi masa aktif subscription.
  • Memproses verifikasi pelunasan transaksi secara otomatis melalui sistem webhook resmi.
  • Menghubungkan akun email kasir dengan hak langganan yang telah dibayar di web.
  • Menyediakan layanan pemulihan akun saat pengguna mengganti atau memformat ulang perangkat ponsel.
  • Mengirimkan informasi teknis penting terkait rilis versi pembaruan aplikasi (.APK) atau bantuan pelanggan melalui WhatsApp resmi.

4 Keamanan Data & Arsitektur Cloud

Kami menerapkan perlindungan berlapis untuk menjaga integritas data Anda:

  • Enkripsi Transportasi Data (TLS/SSL HTTPS): Seluruh komunikasi jaringan antara aplikasi Android, server web Vercel, basis data Supabase, dan gateway Midtrans terenkripsi dengan aman.
  • Row Level Security (RLS): Basis data cloud Supabase dilindungi oleh aturan keamanan tingkat baris (RLS), memastikan setiap tenant/warung hanya dapat mengakses datanya sendiri dan terisolasi dari pengguna lain.

5 Hak Pengguna & Penghapusan Data

Sebagai pengguna, Anda berhak memeriksa, memperbarui data akun, atau mengajukan permohonan penutupan akun beserta penghapusan data cloud Anda kapan saja dengan menghubungi layanan dukungan kami.
